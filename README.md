# twr7bm.github.io

Personal academic site for **Tahseen Rabbani** — AI/ML Postdoctoral Scholar,
University of Chicago. Live at https://twr7bm.github.io

## Stack
A single self-contained `index.html` (inline CSS + vanilla JS, no framework, no
build step). Fonts: Instrument Serif / Instrument Sans / IBM Plex Mono via
Google Fonts. Deploys via GitHub Pages on push to `master`.

## Sketch portraits
The hero photo can be swapped for four *projection + recovery* sketches, all
generated by `generate_sketches.py` (numpy + pillow): a randomized **count**
sketch (pixel-wise), block **DCT**, a **Haar wavelet**, and a low-rank **SVD** —
four bases for the same compress-then-reconstruct idea.

    python3 generate_sketches.py
